## ✨ Features

Flippers provides a suite of 8 interactive, purely client-side tools designed for games, giveaways, parties, and everyday fun:

- **🪙 Coin Flip:** Realistic 3D physics coin flip for simple heads-or-tails decisions.
- **🎲 Dice Roller:** Roll standard or custom-sided dice with dynamic tumbling animations.
- **🎡 Wheel of Names:** A colorful, spinning wheel to randomly pick a winner from a list.
- **🔀 Decision Shuffler:** Add custom options and let the card shuffler highlight a random choice.
- **💬 Comment Picker:** Paste huge lists of comments to transparently pick winners (with deduplication).
- **🃏 Card Shuffler:** Draw random playing cards from a standard 52-card deck.
- **🔢 Number Generator:** Generate unique or repeating random numbers within a custom range.
- **👤 Name Generator:** Instantly generate creative names for Fantasy characters, Gamertags, Pets, or Startups.

## 🔒 Privacy & Performance

Flippers is a **100% Client-Side Application**. 
- **Zero Tracking:** We do not collect, store, or process any of the personal data you enter (like names or options).
- **Lightning Fast:** Because there are no backend servers involved, results are generated instantly via browser-native APIs (`Math.random()`).
- **No Installation:** Everything runs beautifully on Desktop and Mobile browsers.

## 💻 Local Development

Running Flippers locally is incredibly simple. Because it relies purely on HTML, CSS (Tailwind via CDN), and Vanilla JavaScript, there is no build step required.

1. Clone the repository:
   ```bash
   git clone https://github.com/venkatesh0963/flippers.git
   ```
2. Open the folder:
   ```bash
   cd flippers
   ```
3. Open `index.html` in your favorite web browser!
   *(Or use a local server like VS Code Live Server for the best experience).*
